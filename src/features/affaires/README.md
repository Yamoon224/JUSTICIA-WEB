# Module affaires

Périmètre : cahier des charges §6.3-6.4 — Dossier d'affaire, PV, pièces à conviction et scellés. Phase 3.

Composants, hooks et types à responsabilité unique pour ce domaine (§10.2).
Aucune règle juridique ne doit être codée ici : ce module affiche ce que
l'API Laravel autorise et calcule, il ne décide jamais.
